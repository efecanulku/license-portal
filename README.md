# License Portal

Spring Boot + Thymeleaf tabanlı lisans yönetim portalı.

> Proje gereksinimleri şirket dokümanında tanımlı: `internal-docs/lisans_portalı.md` (git'e alınmaz).

## Hızlı Başlangıç (Local)

### Gereksinimler
- Java 17
- Maven
- PostgreSQL

### Ortam değişkenleri
- `env.example` dosyasını kopyalayıp kendi değerlerini gir:
  - Windows (PowerShell) için örnek: `.env` yerine doğrudan sistem env set edebilirsin.
- Zorunlu değişken: `LICENSE_PORTAL_MASTER_KEY`

### Çalıştırma (ileride)
- Uygulama iskeleti kurulduktan sonra komutlar buraya eklenecek.
