# Planlama ve Milestone'lar (20 İş Günü)

Bu repo için 20 iş günlük plan Cursor plan dosyasında tutulur (yerel): `lisans-portali-20-gun_*.plan.md`.

## Milestone özetleri
- **M1 (Gün 1–5)**: Proje iskeleti + DB + Security + temel UI layout
- **M2 (Gün 6–12)**: Admin modülü (ürün/bayi/yetki) + AES secret yönetimi
- **M3 (Gün 13–18)**: Kurum + lisans üretimi + listeleme + sonuç ekranı
- **M4 (Gün 19–20)**: Raporlar + stabilizasyon + teslim hazırlığı

## Çalışma prensibi
- Her gün sonunda: çalışan ekran/akış + küçük commit(ler).
- Her milestone sonunda: `develop` → `main` merge hazırlığı.
